# Temperature Converter

This is a simple Temperature Converter web application built using HTML, CSS, and JavaScript.  
It converts temperature values between Celsius, Fahrenheit, and Kelvin.

## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple and clean user interface
- Input validation for correct values

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Enter the temperature value.
2. Select the temperature unit.
3. Click on the Convert button.
4. The converted temperature values will be displayed.
